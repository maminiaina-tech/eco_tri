# Documentation du Dataset

## Source
**Garbage Classification Dataset**  
Auteur : Mostafa Abla  
Source : https://www.kaggle.com/datasets/mostafaabla/garbage-classification  
Téléchargé via l'API officielle `kagglehub`

## Description
Dataset d'images de déchets recyclables en **5 catégories**.

## Classes (5)
| Classe | Description | Exemples |
|--------|-------------|----------|
| cardboard | Carton | Boîtes, emballages carton |
| metal | Métal | Canettes, boîtes de conserve |
| paper | Papier | Feuilles, journaux |
| plastic | Plastique | Bouteilles, emballages |
| trash | Non recyclable | Déchets divers |

## Statistiques du dataset utilisé
| Split | Nombre d'images |
|-------|-----------------|
| Train (80%) | 3 416 images |
| Test (20%) | 856 images |
| **Total** | **4 272 images** |
